# DragonBites: Food Finding Website for Drexel Students

A full-stack web application designed to help Drexel students browse and filter campus dining options, including restaurants, food trucks, and desserts.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite (SQL)
* **Tools:** Git, GitLab, VS Code, Canva

## My Role (Product Owner & Front-End Developer)
* Served as Product Owner for an Agile team, managing the product backlog and prioritizing features in GitLab across sprint planning cycles.
* Built the front-end interface (filter sidebar, restaurant cards, modal pop-ups) using HTML, CSS, and JavaScript.
* Developed the visual style guide in Canva and implemented CSS pseudo-elements for hover effects and gradients.
* Integrated the front-end with Flask back-end routes built by a teammate.
